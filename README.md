# CAPSTONE 51: Image Classification Mini-Project with Hugging Face

## 1. Project Overview

This project explores image classification using a pre-trained machine learning model available through Hugging Face.

The application will classify animal images and investigate the conditions under which the model produces incorrect predictions.

## 2. Objectives

- Understand image classification and transfer learning.
- Explore pre-trained computer vision models.
- Use Python and Hugging Face for image classification.
- Test the model using at least 20 images.
- Analyze incorrect predictions and possible sources of bias.
- Evaluate an improvement and compare results.
- Verify AI-generated information and document limitations.

## 3. Technologies Used

- Python
- Hugging Face Transformers
- Google Colab
- PyTorch
- GitHub

## 4. Dataset

The project will investigate the Oxford-IIIT Pet Dataset, which contains images of cats and dogs from 37 pet categories.

Dataset website:
https://www.robots.ox.ac.uk/~vgg/data/pets/

## 5. Project Methodology

1. Research image classification and pre-trained models.
2. Select and document the dataset and model.
3. Develop a Python notebook in Google Colab.
4. Test the classifier using animal images.
5. Evaluate predictions and investigate failures.
6. Compare results before and after an improvement.
7. Prepare the final report and presentation.

## 6. Expected Deliverables

- Research report
- Vision-project checklist
- Dataset documentation
- Image classification notebook
- Failure analysis of at least 20 images
- Quiz and answer key
- Seven-slide presentation
- Prompt library
- AI output verification report
- Before-and-after analysis

## 7. Project Status

Currently in the research and planning phase.
Implementation and experimental results will be added as the project progresses.

## 8. Responsible AI

The project will document dataset licensing, potential bias, prediction errors, and model limitations. Experimental results will be reported based on actual testing.
